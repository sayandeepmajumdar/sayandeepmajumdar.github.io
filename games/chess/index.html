Game Rules & Trust Model

📡 Decentralized P2P Architecture

Matches run directly browser-to-browser via WebRTC RTCDataChannels. Both clients run independent chess.js rule engines to validate all incoming and outgoing moves.

⚔️ Standard Chess Rules

  • Castling: Move King two squares towards Rook when squares are unthreatened.
  • En Passant: Capture opponent's double-stepped pawn on the immediately following turn.
  • Promotion: Pawns reaching the back rank transform into Queen, Rook, Bishop, or Knight.
  • End-Game Detection: Automatic Checkmate, Stalemate, 50-move rule, Threefold repetition, and Insufficient material evaluation.
