How to Play

Rules & Simon Duel Modes

Mode 1: Alternating Pattern Builder Player 1 starts by tapping 1 pad. Player 2 must repeat the sequence and append 1 new pad. The sequence grows each turn until someone makes a mistake!
Mode 2: Speed Memory Sprint Both players watch the exact same pattern playback and race to repeat it fastest with 100% accuracy.
Reverse Recall Modifier: When enabled, you must repeat the pattern sequence in reverse order (e.g. 🟢 🔴 🔵 becomes 🔵 🔴 🟢)!
