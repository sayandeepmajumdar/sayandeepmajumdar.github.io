🎲 Cryptographic Randomness

This generator exclusively uses window.crypto.getRandomValues() with uniform rejection sampling. Standard Math.random() is pseudo-random and vulnerable to state prediction; Web Crypto uses OS-level entropy pools.

📐 Real Shannon Entropy

Strength is measured by true mathematical entropy: $E = L \times \log_2(N)$ bits. We calculate exact pool combinations rather than relying on arbitrary superficial length heuristics.

💬 What is Diceware?

Diceware generates passphrases from memorable English words. A 5-word Diceware passphrase provides ~64 bits of entropy—stronger than an 8-character random string, yet effortlessly memorable.

🔒 Zero Storage Guarantee

Generated passwords are never persisted to localStorage, IndexedDB, or cookies, and never leave your device. Make sure to paste or save your password in your password manager before leaving.
