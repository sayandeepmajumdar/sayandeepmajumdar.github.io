💡 How In-Browser PDF Compression Works

1. Image Downsampling

Embedded photos, graphics, and high-DPI scans are re-rendered and compressed as optimized JPEGs, achieving major size reduction.

2. Object & Metadata Stripping

Unused object streams, redundant font subsets, and tracking metadata (author, creation tool) are pruned safely.

3. Pure Text Documents

PDFs containing only vector text and no bitmap images are already compact, so reductions will naturally be lower.
